# 01. システム概要

## 対象システム

本ポートフォリオでは、以下の公開またはローカル環境を対象にQA活動を実施する。

| 対象 | 用途 | 環境 |
|---|---|---|
| SauceDemo | UI機能テスト・主要ユーザージャーニー | 公開デモサイト |
| JSONPlaceholder | APIテスト | 公開練習用API |
| OWASP Juice Shop | 負荷テスト | ローカル環境 |

## 主要ユーザージャーニー

1. ログイン
2. 商品一覧から商品を選択
3. カートへ追加・数量を確認
4. チェックアウト
5. 注文完了結果を確認

## 対象範囲

- ログイン成功・失敗、ロックされた利用者
- 商品一覧、カート、チェックアウトの主要導線
- APIの正常系・異常系・境界値・認証・認可・スキーマ
- Smoke、Load、Stress、Spikeの目的別負荷テスト
- GitHub ActionsでのPR、回帰、夜間、性能テストの分離

## 対象外

- 本番システムへのアクセス
- 他者のサイトへ負荷をかける行為
- 画面の網羅的な視覚デザイン検証
- 探索的テストの固定スクリプト化

## 前提・制約

- SauceDemoは仕様書がないため、実画面の挙動を要求として扱う。
- JSONPlaceholderは外部サービスであり、テスト結果や可用性はサービス側の状態に依存する。
- Juice Shopはローカルで起動する必要があり、負荷テストは外部公開環境で実施しない。
- 負荷テストの閾値は学習用の仮置きであり、実運用時のSLOではない。
